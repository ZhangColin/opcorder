Detailed Requirements

Haikuangyuan Tech is seeking a senior full-stack development team to architect and implement an AI-driven logistics optimization engine. The system will process real-time telemetry data from over 5,000 transport units to minimize fuel consumption and delivery lead times.

Key Responsibilities:

  • Design a scalable microservices architecture using Go or Java Spring Boot.
  • Implement a real-time data ingestion pipeline with Apache Kafka and Flink.
  • Develop predictive routing algorithms using TensorFlow or PyTorch.
  • Build a high-performance dashboard with React and D3.js for visual analytics.

Technical Standards:

All code must adhere to SOE-grade security protocols. Successful candidates will need to demonstrate experience with high-concurrency environments and data encryption at rest/transit.
