# 1. 产品概述
## 1.1 产品背景
在全国OPC（一人公司/超级个体）生态爆发式扩张的背景下，OPC群体最稀缺的资源已从“空间”转变为“真实订单”。海创元作为海国投集团全资控股的国有独资公司，拥有100+私域企业客户、70+合作渠道，覆盖AI教育、政企培训、研学、党建、直播新媒体、AI工具开发六大业务板块。

“接单吧”是海创元与东升原点OPC社区联合打造的OPC撮合交易平台，定位为“以真实订单激活生态”的核心工具，承载需求发布、抢单接单、交付管理、交易保障、OPC认证、社区交流等全流程功能。

## 1.2 产品愿景
成为全国最主要的OPC业务分发基地，让每一个OPC都能“有单可接、有场可练、有路可走”。

## 1.3 产品目标
第一阶段（V1.0，2026年4-6月）：跑通“需求发布 → 抢单/接单 → 交付 → 结算”全流程闭环，完成首批派单试运行。

第二阶段（V1.5，2026年7-9月）：接入i友APP，完善OPC认证、作品集、信用体系，月派单额≥150万。

第三阶段（V2.0，2026年10-12月）：开放第三方需求方入驻，社区生态成熟运转，OPC池≥100人。

# 2. 功能需求详细设计
## 2.1 需求发布模块
### 2.1.1 功能描述
发单方（海创元运营团队或第三方需求方）将客户大订单拆解为结构化子任务后，在平台上发布需求。支持“定向派单”和“公开抢单”两种模式。

### 2.1.2 需求信息字段
|               |              |              |                                                                                              |
|---------------|--------------|--------------|----------------------------------------------------------------------------------------------|
| **字段名称**  | **字段类型** | **是否必填** | **说明**                                                                                     |
| 需求标题      | 文本         | 必填         | 简洁描述任务内容，限50字以内                                                                 |
| 需求类型      | 下拉选择     | 必填         | AI教育课程开发 / 政企AI培训 / AI研学项目 / 党建AI应用 / 直播与新媒体 / AI工具开发定制 / 其他 |
| 需求描述      | 富文本       | 必填         | 详细任务说明，支持图片、附件上传                                                             |
| 需求技能标签  | 多选标签     | 必填         | 如：PPT设计、AI应用开发、视频剪辑、课件制作、提示词工程等                                    |
| 需求OPC等级   | 单选         | 必填         | C级（新手）/ B级（进阶）/ A级（专家）/ 不限                                                  |
| 预算范围      | 数值区间     | 必填         | 单位：元，支持区间填写如500-3000                                                             |
| 交付截止日期  | 日期选择器   | 必填         | 不得早于当前日期+3天                                                                         |
| 里程碑节点    | 动态表单     | 选填         | 可添加多个里程碑节点，含节点名称、截止日期、交付物描述                                       |
| 派单模式      | 单选         | 必填         | 公开抢单 / 定向派单                                                                          |
| 定向邀约OPC   | 人员选择器   | 定向模式必填 | 从OPC生态池中搜索并选择目标OPC                                                               |
| 抢单截止时间  | 日期时间     | 公开模式必填 | 抢单窗口关闭时间                                                                             |
| 参考材料/附件 | 文件上传     | 选填         | 支持PDF、Word、图片等，单文件≤20MB                                                           |

### 2.1.3 需求状态机
草稿 → 待审核 → 已发布（抢单中）→ 已匹配（已确认OPC）→ 执行中 → 待验收 → 已完成 / 已关闭

审核规则：海创元运营团队对所有需求进行内容审核，确保任务描述清晰、预算合理、交付标准明确。审核不通过需附具体原因退回。

### 2.1.4 业务规则
① 每条需求自动生成唯一编号（格式：JDB-YYYYMM-XXXX）。

② 发单方可在“抢单中”状态前编辑需求，抢单开始后仅可编辑非核心字段。

③ 定向派单模式下，被邀约OPC若48小时内未响应，系统自动转为公开抢单。

④ 发单方可对需求设置“紧急”标记，紧急需求在抢单列表中置顶展示。

## 2.2 抢单/接单模块
### 2.2.1 公开抢单流程
① OPC在“抢单大厅”浏览已发布需求，支持按需求类型、技能标签、OPC等级、预算范围、截止日期筛选排序。

② OPC点击“我要抢单”后，需填写接单申请表（包含：简要方案描述、预计完成时间、相关作品集链接）。

③ 发单方收到抢单申请列表，可查看OPC资料、作品集、信用评分，选择“确认接单”或“婉拒”。

④ 确认接单后自动生成交易订单，双方进入执行阶段。

### 2.2.2 定向派单流程
① 发单方创建需求时选择“定向派单”模式，从OPC生态池中选择目标OPC。

② 被邀约OPC收到系统通知（站内消息 + 微信服务通知），点击“接受邀约”或“婉拒”。

③ OPC接受后自动生成交易订单；OPC婉拒或超时未响应，发单方可更换目标OPC或转公开抢单。

### 2.2.3 智能推荐机制（V1.5）
平台根据需求技能标签、OPC能力标签、历史交付评分、信用等级自动推荐匹配度最高的OPC候选人，发单方可一键邀约。

## 2.3 完单交付模块
### 2.3.1 交付全流程
|                |                                     |            |                                |
|----------------|-------------------------------------|------------|--------------------------------|
| **阶段**       | **操作**                            | **触发方** | **系统行为**                   |
| **执行中**     | OPC按任务说明书开展工作             | OPC        | 进度条展示，支持消息沟通       |
| **里程碑提交** | OPC按节点提交阶段性交付物           | OPC        | 自动通知发单方检查             |
| **里程碑审查** | 发单方检查阶段交付物，通过/打回修改 | 发单方     | 打回需附修改意见，记录修改次数 |
| **最终交付**   | OPC提交全部交付物                   | OPC        | 触发双重质检流程               |
| **内部质检**   | 海创元运营团队审核交付物质量        | 平台管理员 | 质检结果记录在案               |
| **客户验收**   | 发单方最终确认验收或要求返工        | 发单方     | 验收通过触发结算流程           |

### 2.3.2 交付物规范
支持上传文件类型：PDF、Word、PPT、Excel、图片、视频、压缩包、代码仓库链接等。单文件上限200MB，单订单总容量上限1GB。所有交付物平台存档保留180天。

### 2.3.3 修改与争议机制
① 每个里程碑节点最多允许3次修改，超过3次触发争议处理流程。

② 争议由平台管理员介入调解，48小时内给出处理结果。

③ 争议记录影响OPC信用评分和发单方信誉等级。

## 2.4 交易支付与保障模块
### 2.4.1 结算流程
① 发单方在需求发布时预付订单金额至平台担保账户（托管）。

② 客户验收通过后，系统自动触发分成结算：

### 2.4.2 分成比例规则
|                |          |                              |                       |
|----------------|----------|------------------------------|-----------------------|
| **分成方**     | **比例** | **说明**                     | **结算时点**          |
| **OPC接单方**  | 50%-70%  | 根据任务难度和OPC等级浮动    | 验收通过后3个工作日内 |
| **发单方**     | 20%-40%  | 包含商务承接、质量管理成本   | 验收通过后3个工作日内 |
| **平台服务费** | 10%      | 其中7%归海创元、3%归原点社区 | 随订单结算同步扣除    |

### 2.4.3 交易保障机制
① 资金托管：订单金额由平台第三方支付机构托管，确保资金安全。

② 国企信用背书：海创元以国企主体承担质量兜底责任，保障OPC及时结算。

③ 超时自动确认：发单方收到交付物后7个自然日未操作，系统自动确认验收通过。

④ 负面保护：OPC连续2单质检不通过，自动降级并暂停抢单权限7天。

## 2.5 OPC认证与能力管理模块
### 2.5.1 三级认证体系
|              |                                            |                                              |                  |                        |
|--------------|--------------------------------------------|----------------------------------------------|------------------|------------------------|
| **等级**     | **认证条件**                               | **可接任务范围**                             | **单项金额区间** | **特权**               |
| **C级 新手** | 完成L1能力认证课程（8学时）                | 文案创作、课件美化、简单数据处理等标准化任务 | 500-3,000元      | 参与公开抢单           |
| **B级 进阶** | 完成L2认证课程（20学时）且历史交付评分≥4.0 | AI应用开发、培训课程定制、中等复杂度任务     | 3,000-20,000元   | 优先抢单权             |
| **A级 专家** | 完成L3认证且历史交付评分≥4.5               | 政企培训定制、党建系统开发、高价值长周期项目 | 20,000-200,000元 | 参与定向派单、最高分成 |

### 2.5.2 能力标签体系
每个OPC具有多维能力标签，用于智能匹配：

技能标签（多选）：PPT设计 / 视频剪辑 / AI应用开发 / Vibe Coding / 提示词工程 / 教案设计 / 文案撰写 / 直播运营 / 短视频制作 / 数据处理 / Web开发 / 小程序开发

行业标签（多选）：AI教育 / 政务 / 党建 / 企业培训 / 研学 / 新媒体 / 营销

能力标签来源：认证课程结业自动获得 + 完成订单交付后自动累积 + 管理员手动添加。

### 2.5.3 信用评分体系
基础分：新注册OPC初始信用分4.0分（满分5.0）。

加分项：按时交付+0.1 / 一次性通过质检+0.1 / 客户好评+0.1 / 完成能力认证+0.2。

扣分项：超时交付-0.2 / 质检不通过-0.3 / 中途放弃-0.5 / 争议责任方-0.3。

信用分影响：低于3.5分暂停抢单权限7天；低于3.0分移出生态池。

| **用户（User）**               | ID、昵称、手机、角色、状态           | 1:1 OPC资料 / 发单方资料                   | 统一账户体系，角色区分权限 |
| **OPC资料（OpcProfile）**      | ID、等级、能力标签、信用分、简介     | 1:N 作品 / 1:N 订单 / 1:N 认证记录         | OPC核心画像                |
| **需求（Demand）**             | ID、编号、类型、状态、预算、截止日期 | N:1 发单方 / 1:N 抢单申请 / 1:1 订单       | 支持多里程碑               |
| **抢单申请（BidApplication）** | ID、需求ID、OPC ID、方案描述、状态   | N:1 需求 / N:1 OPC                         | 抢单、定向邀约统一模型     |
| **交易订单（Order）**          | ID、编号、金额、状态、分成规则       | 1:1 需求 / N:1 OPC / 1:N 交付物 / 1:1 结算 | 订单全生命周期管理         |
| **交付物（Deliverable）**      | ID、订单ID、里程碑ID、文件、状态     | N:1 订单 / N:1 里程碑                      | 支持多文件、多版本         |
| **结算记录（Settlement）**     | ID、订单ID、各方金额、状态           | 1:1 订单                                   | 自动计算分成               |
| **作品（Portfolio）**          | ID、OPC ID、类型、封面、描述         | N:1 OPC / 可关联订单                       | OPC展示窗口                |
| **认证记录（Certification）**  | ID、OPC ID、等级、课程、状态         | N:1 OPC / N:1 课程                         | 培训与认证联动             |

# 9. 验收标准
## 9.1 V1.0核心验收标准
|                     |                                                                             |
|---------------------|-----------------------------------------------------------------------------|
| **验收项**          | **标准**                                                                    |
| **需求发布流程**    | 发单方可完整创建需求，包含所有必填字段，支持公开抢单和定向派单两种模式      |
| **抢单接单流程**    | OPC可浏览、筛选、抢单；发单方可查看抢单申请并确认；定向邀约可正常触达并响应 |
| **交付流程**        | OPC可提交交付物，发单方可审查/打回/确认验收，里程碑节点可正常流转           |
| **结算流程**        | 验收通过后自动触发分成计算，各方金额正确，结算状态可跟踪                    |
| **OPC注册与作品集** | OPC可注册、完善资料、上传作品，发单方可浏览OPC作品集                        |
| **消息通知**        | 抢单结果、订单状态变更、定向邀约等关键事件均有站内通知                      |

# 10. 术语表
|              |                                                                           |
|--------------|---------------------------------------------------------------------------|
| **术语**     | **定义**                                                                  |
| **OPC**      | One Person Company，一人公司/超级个体，指以个人或极小团队独立运营的创业者 |
| **发单方**   | 在平台发布需求的一方，V1.0阶段主要为海创元运营团队                        |
| **抢单**     | OPC主动申请承接平台上公开发布的需求                                       |
| **定向派单** | 发单方根据OPC能力匹配直接邀约特定OPC承接任务                              |
| **里程碑**   | 订单执行过程中的阶段性交付节点                                            |
| **i友APP**   | 原点社区现有的社区服务平台应用                                            |
| **能力标签** | 用于描述OPC专业技能和行业经验的结构化标签                                 |
| **信用分**   | 基于OPC历史交付表现的量化评分，影响抢单权限和等级                         |

# 附录：关键业务流程图
## A. 公开抢单全流程
发单方创建需求 → 平台审核 → 发布至抢单大厅 → OPC浏览并提交抢单申请 → 发单方选择确认OPC → 生成交易订单 → OPC执行交付（里程碑节点循环）→ 发单方验收 → 平台质检 → 自动结算分成 → 双方互评 → 订单完成

## B. 定向派单全流程
发单方创建需求（选择定向模式）→ 选择目标OPC → 平台审核 → 系统发送邀约通知 → OPC接受/婉拒（48h超时自动转公开）→ 生成交易订单 → 执行交付 → 验收结算

## C. OPC能力认证流程
OPC报名L1/L2/L3课程 → 线下培训（原点学堂）→ 考核通过 → 自动发放认证徽章 → 能力标签更新 → OPC等级升级 → 解锁对应等级任务权限
