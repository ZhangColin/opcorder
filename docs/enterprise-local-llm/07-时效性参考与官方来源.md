## 1. 来源使用规则

1. **官方矩阵优先**：芯片厂商、服务器 OEM、OS、容器/编排、推理引擎四方都应有证据。
2. **“能运行”不等于“受支持”**：实验成功只能作为实测证据，不能替代厂商支持边界。
3. **记录具体版本页**：`latest` 可用于发现资料，设计冻结时应另存准确版本 URL、PDF 或受控快照。
4. **型号与价格分离**：本手册不给固定价格；正式报价使用授权渠道的含税、币种、有效期和交期数据。
5. **许可逐版本审查**：模型名相同不代表不同版本的许可、模型卡或用途限制相同。
6. **网页不是唯一证据**：归档采购合同、授权书、许可证原文、哈希、SBOM、测试结果和审批单。

许可审查不能只看仓库顶部标签，至少归档：

- 基础模型、Tokenizer、Embedding、Rerank 和适配器的准确版本与许可原文；
- 商用、内网服务、微调、合并、量化、衍生物、输出、再分发和地域限制；
- 驱动、算子、推理引擎、训练框架、基础镜像、字体和解析器的依赖许可；
- NOTICE、署名、源码提供、用户规模、收入门槛、用途限制和终止条款；
- 客户法务/采购的适用结论、剩余风险及复核日期。

## 8. 采购前最终复核

- [ ] BOM 中每个料号与最终报价、交期、保修和备件条款一致。
- [ ] 服务器 OEM 明确支持所选 GPU、网卡、NVMe、固件和功率配置。
- [ ] OS/内核/驱动/运行时/通信库/容器/设备插件/引擎形成闭合兼容矩阵。
- [ ] 目标模型、精度、量化、上下文、多卡/多机方式在候选硬件实测。
- [ ] 模型、软件和数据许可原文与实际版本匹配，客户法务/采购已签字。
- [ ] 在线、半离线或完全隔离的制品获取和补丁升级责任已写入方案。
- [ ] 价格标注币种、税率、有效期、付款条件和不含项；没有把临时报价写入长期方法论文档。
- [ ] 所有 `latest` 页面已替换或补充为设计冻结时的准确版本证据。
