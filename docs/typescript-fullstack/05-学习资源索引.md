## 核验口径与使用方法

- **统一核验日期：2026-08-27**。下列链接均在该日期通过 Web Search 定位，并对最终 URL 执行 Web Fetch，确认能返回对应正文（不是仅凭记忆列出）。站点之后仍可能迁移。
- 本表是一次性可访问性核验，不是网页存档或持续可用承诺。表中的链接文字就是核验时的页面标题/栏目，URL 是重定向后的最终入口；“正文中文、混合、英文”在各组说明中标明。
- 版本号另以官方发布页或 npm registry 的 stable/latest 标签交叉检查；预发布标签不作为推荐依据。核验不保存第三方页面全文，后续应按 E 节重新执行。
- “滚动文档”表示站点随 latest 版本更新，不代表你的项目应自动追随 latest。先查看仓库锁文件、`engines` 和框架迁移指南。
- “免费”指正文可公开阅读，不代表云服务、证书、模型 API 或配套课程免费。
- 中文优先，但中文社区翻译可能落后；凡涉及安全、缓存、迁移或废弃 API，必须回看同项官方英文 latest。
- 每阶段只采用“**一项主线 + 官方参考 + 最多一项专项补充**”。先做[学习路径](04-学习路径.md)练习，再查参考；禁止用视频播放量代替掌握标准。

## D. 已发现但不应作为主线的内容

1. **旧 TypeScript 手册入口** `https://www.typescriptlang.org/zh/docs/handbook/intro.html`：核验时返回 404 页面。使用上表的[官方中文文档入口](https://www.typescriptlang.org/zh/docs/)或具体 Handbook 2 页面，避免收藏旧入口。
2. **第三方中文镜像/搬运站**：即使当前可打开，也可能缺来源版本、勘误和更新承诺。可帮助搜索中文术语，不应用于确认安全默认值或 API 签名。
3. **基于 Create React App、Pages Router、Nest 微服务起步、旧 Node EOL 版本的课程**：可借鉴不依赖版本的解释；跳过初始化、构建、缓存与部署章节。
4. **“一套代码自动生成整个 SaaS/RAG”的模板课**：不满足逐行手敲和边界理解要求，只能在完成 S7/S9 后作为代码审查材料。
5. **证书导向付费训练营**：未纳入主清单。若购买，先核对最近更新时间、源码依赖大版本、退款条款及是否覆盖失败路径、迁移和测试；证书不能替代[跨阶段能力门](04-学习路径.md#2-跨阶段能力门)。

## E. 每次开学与升级前的复核清单

- [ ] 链接仍返回正文，不是 404、登录墙、营销页或旧版本归档。
- [ ] Node 仍在 LTS 支持期；TypeScript、pnpm、框架与测试工具满足彼此的引擎约束。
- [ ] 阅读目标版本的 migration guide、security advisory 与 breaking changes。
- [ ] 中文页与英文 latest 的关键配置、默认缓存、安全行为一致。
- [ ] 付费 API 的价格、区域、数据保留、速率限制和可用模型已另行记录。
- [ ] 跳过项仍与当前学习目标一致；只有出现真实需求或可测瓶颈才解锁高级主题。
- [ ] 没有因教程诱导引入微服务、Kubernetes 或事件溯源；若要升级，先提交包含量化证据的 ADR。

### 核验记录最小格式

再次核验时，在变更说明中记录：核验时间（含时区）、最终 URL、页面标题、正文语言、HTTP/访问结果、显示的版本或更新时间、是否需登录/付费、与仓库锁定大版本是否一致。对安全、迁移、缓存和认证资料，必须同时记录对应英文官方页。
